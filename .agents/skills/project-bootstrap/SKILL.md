# 按需求初始化项目

## 输入与入口

必需输入是需求内容和目标目录。先读取目标项目的 `AGENTS.md`、`.memories/README.md` 和 `.tasks/initialization.md`；模板中的这些路径均以目标项目根目录为基准。

完整阶段与验收见 [初始化流程](../../../docs/bootstrap.md)。需求不足时登记问题，澄清影响后续方案的部分；可独立进行的工作继续推进。

## 执行

1. 确认目标目录、已有实现和初始化进度。保留用户已有文件，续接未完成阶段，不重复创建项目。
2. 依据原始需求填写 `docs/requirements/project.md`，建立需求编号和验收条件。
3. 按约束完成 `docs/decisions/0001-tech-stack.md`。推荐与确定分开记录；未确定的关键方案不提前落地依赖。
4. 按已确定技术的惯例生成最小可运行工程，记录目录职责，跑通一条与真实需求有关的路径。
5. 项目化 rules、skills 和需要的 MCP。按实际客户端核实加载方式，保留单一来源；未配置或未验证的能力如实登记。
6. 根据需求、决策、实际代码和执行结果填充八个基础记忆文件及索引。计划中的内容标为设计，不将预期效果写成已实现事实。
7. 逐阶段完成 verify，更新初始化任务，改写产品 README，交付结果与剩余事项。

## 完成与停止条件

完成以 `docs/bootstrap.md` 的验收为准，不以文件数量为准。必需输入、依赖或运行条件缺失时，保留已完成结果，准确记录受阻阶段、影响和需要的输入。外部工具的安装、凭据配置与写操作遵循当前授权；本技能不自行扩展授权范围。
