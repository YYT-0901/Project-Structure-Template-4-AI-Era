## 接入流程

1. 根据任务选择可信服务，核实官方安装方式、版本、传输方式与客户端配置格式。
2. 确认连接对应的项目和环境，区分只读与写能力；按需授予权限。
3. 仓库只存配置示例和凭据变量名，真实凭据由本地或团队凭据机制提供。
4. 在实际客户端配置连接，用最小只读调用验证目标与能力，记录日期、结果及脱敏证据。
5. 未连通时登记限制与替代办法；不能把返回的错误当成业务查询结果，也不能猜测服务标识或环境。

## 环境与操作边界

初始化时按项目填写允许环境、资源范围及写操作限制，写入 `AGENTS.md` 或关联专项规则。只有项目明确需要时才引入部署与数据库操作能力。配置存在不代表已连接，连接成功不代表获准执行任意操作。
