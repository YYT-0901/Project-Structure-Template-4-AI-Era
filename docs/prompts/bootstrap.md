# 初始化提示词

复制下面内容，把两处输入替换为真实值后发给 AI。

```text
请使用当前仓库的 Project Structure Template 初始化项目。

需求文档：<填写实际路径或提供需求正文>
目标项目目录：<填写实际目录>

先读 AGENTS.md、.memories/README.md、docs/bootstrap.md，以及已有的
.tasks/initialization.md；不要覆盖现有实现或已确定的技术决策。

按照 docs/bootstrap.md 完成需求梳理、技术选型、工程骨架、AI 协作配置、
项目知识和验收。使用 .agents/skills/project-bootstrap/SKILL.md 作为执行入口；
如果客户端不能发现 skill，直接读取该文件并遵循工作流。

保留原始需求和来源。影响选型或业务含义的缺失信息先澄清；
其他工作继续推进。不要把推荐方案当成已确定约束，不要为填满模板引入组件。

确定技术栈后，按框架惯例生成目录，并记录职责、依赖方向和真实运行命令。
将需要的规则、技能与 MCP 配置项目化，验证当前客户端确实能使用它们。
根据需求、决策、代码和执行结果填写 .memories/，明确区分设计和已实现事实。

每完成一个阶段就更新 .tasks/initialization.md，附产出与验证证据。
最终交付说明可运行的最小路径、检查结果、未完成事项及其影响。
未实际执行的步骤不得标记通过，必需验收项未通过不得宣布初始化完成。
```
